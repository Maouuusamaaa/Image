# Kirim Kode Animasi Asli

Gunakan file ini sebagai panduan untuk mengirim sumber animasi yang benar-benar digunakan pada versi sebelumnya. Tujuannya agar pengembangan berikutnya bisa melanjutkan proyek yang sama, bukan membuat ulang dari nol.

## Cara mengirim

**Pilihan A — unggah berkas kode ke percakapan ChatGPT**
1. Lampirkan berkas proyek animasi yang sebenarnya. Contoh: `.py`, `.js`, `.ts`, `.html`, `.css`, `.json`, `.blend`, atau arsip `.zip`.
2. Jika terdiri dari banyak berkas, kirim satu arsip ZIP yang berisi kode, konfigurasi, dan aset yang memang boleh dibagikan.
3. Jangan sertakan token, password, API key, cookie, atau rahasia lain.

**Pilihan B — masukkan tautan repository**
Tempel URL repository GitHub tempat kode animasi berada, misalnya:
`https://github.com/OWNER/REPOSITORY`

Jika kode ada di branch atau commit tertentu, sertakan tautan branch/commit tersebut. Pastikan repository dapat diakses atau koneksi GitHub memiliki izin yang diperlukan.

## Jika kode terdiri dari banyak file

Sertakan struktur direktori, dependency/requirements, dan instruksi menjalankan proyek. Jika hasil animasi bergantung pada aset, sertakan aset yang diperlukan atau jelaskan lokasinya.

## Setelah kode diterima

1. Periksa struktur dan status repository terlebih dahulu.
2. Identifikasi entry point, dependensi, dan cara menghasilkan render sebelumnya.
3. Catat baseline sebelum mengubah apa pun.
4. Simpan perubahan, aset, render, hasil uji, dan laporan di folder yang sesuai.
5. Verifikasi commit dan tautan GitHub sebelum menyatakan pekerjaan tersimpan.

**Penting:** File Markdown ini adalah panduan pengiriman, bukan tempat menempelkan seluruh kode sumber. Kirim kode sebagai lampiran atau berikan URL repository sebenarnya. Jangan menaruh kode proyek di repository aset ini kecuali memang repository yang tepat.

# Generated animation outputs

The renderer writes the MP4 and numbered PNG frames here. The repository workflow in `.github/workflows/render-stickman.yml` renders the current animation, creates a contact sheet, and commits generated deliverables after source changes.

- `stickman-battle-v1.mp4` — rendered animation (12 seconds, 30 FPS).
- `contact-sheet.png` — representative frame overview.
- `frames/` — numbered frame sequence generated by the renderer; retained in CI workspace and not individually versioned to avoid hundreds of near-duplicate binary files.

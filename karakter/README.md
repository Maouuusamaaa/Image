# Referensi Karakter

Folder ini digunakan untuk menyimpan gambar referensi bentuk karakter bagi proyek Stickman Battle Animation.

## Cara menggunakan

- Unggah gambar karakter ke folder `karakter/`.
- Beri nama file yang jelas, misalnya `karakter-utama.png`, `karakter-lawan.png`, atau `pose-referensi-01.jpg`.
- Sebaiknya gunakan gambar dengan latar yang jelas dan seluruh bagian tubuh terlihat jika proporsi tubuh atau pose perlu ditiru.
- Jika satu karakter memiliki beberapa sudut atau pose, simpan semuanya di folder ini dengan nama file yang konsisten.

Gambar yang diunggah akan menjadi referensi desain; animasi tidak akan diubah otomatis hanya dengan mengunggahnya. Referensi akan ditinjau sebelum diterapkan ke kode animasi.
